# 🛠️ Security Tools

Kumpulan tools keamanan yang aku bangun sendiri sebagai bagian dari perjalanan belajar penetration testing dan offensive security.

Setiap tool dibuat untuk menyelesaikan masalah nyata yang ditemui saat latihan di home lab, bukan sekadar latihan coding, tapi alat yang benar-benar dipakai.

---

## 📁 Daftar Tools

| Tool | Deskripsi | Bahasa |
|------|-----------|--------|
| [port-scanner](./port-scanner/) | Scanner port TCP untuk cek port terbuka/tertutup pada target | Python |
| [network-sniffer](./network-sniffer/) | Sniffer jaringan untuk menangkap dan menganalisis paket | Python |

---

## 🎯 Tujuan Repo Ini

- Latihan membangun security tools dari nol
- Memahami cara kerja tools yang biasa dipakai dalam pentesting
- Dokumentasi proses belajar offensive security secara praktis
